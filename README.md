# 图片转PDF

这个网页的目的是在用户本地把图片转换为PDF，然后提供下载。

## 特性

- 基于 Vite 的单页网页，适配桌面端和移动端。
- 支持点击选择或拖放导入多张 JPG、PNG 和 WEBP 图片。
- 图片只在浏览器本地解析和转换，不上传到任何服务器。
- 展示图片缩略图、文件名、像素尺寸、文件大小及页码。
- 可使用鼠标或触摸拖动卡片手柄调整 PDF 页面顺序。
- 每张图片提供置顶、上移一页、下移一页和置底四个图标按钮，并可单独删除。
- 可自定义下载文件名，自动过滤操作系统不允许的文件名字符。
- 提供 A4、Letter 和适应原图三种页面尺寸。
- A4 和 Letter 模式支持纵向/横向；适应原图模式会根据每张图片自动设定页面方向。
- 提供无边距、窄边距和宽边距选项；图片按比例居中适配，不会被拉伸或裁切。
- 提供 0%–100% 图像质量滑块：100% 直接使用原图，其余档位在本地通过降低分辨率和 JPEG 编码质量减小 PDF 体积。
- 使用 jsPDF 在客户端生成并直接下载多页 PDF。
- 提供生成进度、成功、格式过滤及失败状态反馈。
- 支持键盘操作文件选择区，并遵循用户的减少动画系统设置。

## 视觉方向

- 采用纸张感的暖白背景、高对比黑色与珊瑚橙强调色。
- 整体采用上下布局：PDF 设置位于上方，图片导入与顺序控制位于下方。
- 窄屏时所有设置改为单列，图片卡片的操作按钮换行排列，避免文件名和按钮互相挤压。
- 精简顶部标题区与底部说明，保留纸张感暖白、黑色与珊瑚橙视觉系统。

## 部署

- Vite 使用相对基础路径 `./`，使构建资源可在 GitHub Pages 项目子路径下正常加载。
- 推送到 `master` 分支时，GitHub Actions 会使用 Node.js 24 安装依赖、构建 `dist` 并自动部署到 GitHub Pages。
- 部署工作流也支持从 GitHub Actions 页面手动触发。
